# shadcn-egui-icons-remixicon

The Remix Icon (last Apache-2.0 release) icon set for [shadcn-egui](https://crates.io/crates/shadcn-egui),
the shadcn/ui design system for egui.

You do not depend on this crate directly. Enable the `icons-remixicon` feature
of `shadcn-egui` and select the icon set in your theme.
