# shadcn-egui-font-instrument-sans

The Instrument Sans font for [shadcn-egui](https://crates.io/crates/shadcn-egui),
the shadcn/ui design system for egui.

You do not depend on this crate directly. Enable the `font-instrument-sans` feature
of `shadcn-egui` and select the font in your theme.
