# shadcn-egui-icons-hugeicons

The Hugeicons (free) icon set for [shadcn-egui](https://crates.io/crates/shadcn-egui),
the shadcn/ui design system for egui.

You do not depend on this crate directly. Enable the `icons-hugeicons` feature
of `shadcn-egui` and select the icon set in your theme.
