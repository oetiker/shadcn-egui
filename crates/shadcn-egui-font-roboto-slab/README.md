# shadcn-egui-font-roboto-slab

The Roboto Slab font for [shadcn-egui](https://crates.io/crates/shadcn-egui),
the shadcn/ui design system for egui.

You do not depend on this crate directly. Enable the `font-roboto-slab` feature
of `shadcn-egui` and select the font in your theme.
