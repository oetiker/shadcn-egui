# shadcn-egui plugin 0.4 implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rewrite the `egui-shadcn` 0.3.2 Claude Code plugin as the `shadcn-egui` 0.4.0 plugin with the skills `build-ui` and `port-component`, built on the published crates.

**Architecture:** The plugin is Markdown under `skills/` plus two JSON manifests under `.claude-plugin/`. Correctness is enforced from the crate's test suite: every `rust` fence in the skills compiles as a rustdoc doctest through `#[cfg(doctest)]` items in `crates/shadcn-egui/src/lib.rs`, and `crates/shadcn-egui/tests/skills.rs` checks the manifests, the component map, the feature names and the doctest wiring. Create release PR bumps the plugin through three new `version_files` entries.

**Tech Stack:** Rust (egui 0.34, shadcn-egui 0.4.0), rustdoc doctests, Claude Code plugin manifests, repo-infra release workflows.

**Spec:** `docs/superpowers/specs/2026-10-13-plugin-0.4-design.md`

## Global Constraints

- Branch `feat/plugin-0.4` in `/home/oetiker/checkouts/shadcn-egui`; never commit to `main`.
- Every cargo command gets `--jobs 4`; every `cargo test` also `-- --test-threads 4`. No `/tmp`; scratch files go under `/scratch/oetiker/claude-tmp/shadcn-egui-plugin/`.
- Plugin name `shadcn-egui`; marketplace name `shadcn-egui`; skills `build-ui` and `port-component`.
- Plugin version `0.4.0` in `plugin.json` and in the marketplace entry; marketplace source `{"source": "github", "repo": "oetiker/shadcn-egui", "ref": "v0.4.0"}`.
- The app depends on `egui = "0.34"`; the crate does not re-export egui.
- Every code fence in `skills/` carries a language tag (`rust`, `bash`, `toml`, `text`, `json`).
- `rust` snippets are complete items (functions, structs) without hidden `# ` lines, compile with default features and with `--all-features`, and never need a `font-*` or `icons-*` feature. `rust,ignore` only for a signature sketch.
- House style (`repo-infra:writing-style`): no em or en dashes, "for example" never `e.g.`, sentence-case headings, no rhetorical contrasts. Load that skill before writing any prose.
- Repository is public: no private project names or paths in committed text.
- `.claude-plugin/` and `skills/` text never names `egui-shadcn` or `egui_shadcn`, except the migration commands in `CHANGES.md` and `README.md`.
- No new runtime or dev dependency.
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. A reference file added to `skills/` later without a doctest item: its snippets would never compile in CI. `tests/skills.rs` asserts every `.md` under `skills/` is named in `lib.rs` (Task 2).
2. Someone reformats `plugin.json` or `marketplace.json` (indentation): the `version_files` regexes stop matching and the release PR fails or skips the plugin. `tests/skills.rs` asserts each regex's line shape occurs exactly once (Task 1).
3. A skill snippet that compiles only with a font or icon feature passes the `--all-features` gate and fails the default gate, or the other way round: both gates run doctests (Task 2 step runs both).
4. A component added to `src/components/` without a row in `component-map.md`: app builders never learn it exists. `tests/skills.rs` checks the rows (Task 4).
5. A skill names a feature such as `font-geist-sans` that the crate does not have: `cargo add --features` fails for the user. `tests/skills.rs` checks every `font-*` and `icons-*` name in the skills (Task 4).

```rust
//! The Claude Code plugin under skills/ and .claude-plugin/ stays true to
//! the crate: versions, doctest wiring, component map, feature names.

const PLUGIN: &str = include_str!("../../../.claude-plugin/plugin.json");
const MARKETPLACE: &str = include_str!("../../../.claude-plugin/marketplace.json");
const REPO_INFRA: &str = include_str!("../../../.github/repo-infra.json");
const WORKSPACE: &str = include_str!("../../../Cargo.toml");

fn lines_starting<'a>(text: &'a str, prefix: &str) -> Vec<&'a str> {
    text.lines().filter(|l| l.starts_with(prefix)).collect()
}

fn workspace_version() -> &'static str {
    let line = lines_starting(WORKSPACE, "version = \"")[0];
    line.trim_start_matches("version = \"").trim_end_matches('"')
}

#[test]
fn plugin_versions_follow_the_workspace() {
    let v = workspace_version();
    assert_eq!(
        lines_starting(PLUGIN, "  \"version\": \""),
        vec![format!("  \"version\": \"{v}\",").as_str()],
        "plugin.json version"
    );
    assert_eq!(
        lines_starting(MARKETPLACE, "      \"version\": \""),
        vec![format!("      \"version\": \"{v}\",").as_str()],
        "marketplace.json plugin entry version"
    );
    assert_eq!(
        lines_starting(MARKETPLACE, "        \"ref\": \"v"),
        vec![format!("        \"ref\": \"v{v}\"").as_str()],
        "marketplace.json source ref"
    );
}

#[test]
fn release_bumps_the_plugin() {
    for (path, pattern) in [
        (".claude-plugin/plugin.json", r#"^  \"version\": \"[^\"]*\""#),
        (".claude-plugin/marketplace.json", r#"^      \"version\": \"[^\"]*\""#),
        (".claude-plugin/marketplace.json", r#"^        \"ref\": \"v[^\"]*\""#),
    ] {
        let entry = format!("\"path\": \"{path}\",\n      \"pattern\": \"{pattern}\"");
        assert!(
            REPO_INFRA.contains(&entry),
            "repo-infra.json has no version_files entry {path} {pattern}"
        );
    }
}

#[test]
fn plugin_is_named_shadcn_egui() {
    assert!(PLUGIN.contains("\"name\": \"shadcn-egui\""));
    assert!(PLUGIN.contains("\"repository\": \"https://github.com/oetiker/shadcn-egui\""));
    assert!(MARKETPLACE.starts_with("{\n  \"name\": \"shadcn-egui\","));
    assert!(MARKETPLACE.contains("\"repo\": \"oetiker/shadcn-egui\""));
    for text in [PLUGIN, MARKETPLACE] {
        assert!(!text.contains("egui-shadcn"), "old name left in a manifest");
    }
}
```

const LIB: &str = include_str!("../src/lib.rs");

fn skill_files() -> Vec<String> {
    let root = concat!(env!("CARGO_MANIFEST_DIR"), "/../../skills");
    let mut out = Vec::new();
    for skill in std::fs::read_dir(root).unwrap() {
        let dir = skill.unwrap().path();
        let name = dir.file_name().unwrap().to_str().unwrap().to_owned();
        out.push(format!("{name}/SKILL.md"));
        if let Ok(refs) = std::fs::read_dir(dir.join("references")) {
            for r in refs {
                let f = r.unwrap().file_name().into_string().unwrap();
                if f.ends_with(".md") {
                    out.push(format!("{name}/references/{f}"));
                }
            }
        }
    }
    out.sort();
    out
}
